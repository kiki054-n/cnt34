# 基本方程式 — The Fundamental Equation

*理論ドキュメント 01 — 三四式（TTT理論）が、あらゆる存在 $P$ を記述するための基礎方程式。*

## 0. 位置づけ

[`00-dual-pole.md`](00-dual-pole.md) では、双極（00）の引き合いから、位置の3次元（X, Y, Z）と方向の3次元（U, V, W）が生まれる過程を示した。

$$P = xX + yY + zZ + uU + vV + wW$$

本稿では、この6次元を1つの状態方程式として定式化し直す。特に「方向」を担う3次元を、実数の回転座標（U, V, W）から、虚数的な数を用いた表記（R, I, J）へと書き換える。

## 1. 基本方程式

### 1.1 静的記述（6次元ベクトル方程式）

三四式（TTT理論）は、あらゆる存在 $P$ を以下の6次元ベクトル方程式で記述する。

$$P = xX + yY + zZ + rR + iI + jJ$$

$P$ は「存在の完成状態」を表す。右辺の6つの項はそれぞれ独立した次元を持ち、それらの総和として $P$ が形成される。

| 項 | 次元 | 意味 |
| :--- | :--- | :--- |
| $xX,\ yY,\ zZ$ | 位置の3次元 | どこに物質があるか（空間座標） |
| $rR,\ iI,\ jJ$ | 方向の3次元 | どちらを向いているか（回転・配向） |

### 1.2 表記について — クォータニオンと「同じで違う」

空間座標（x, y, z）と回転座標（U, V, W）から出発し、回転座標の3成分を、虚数的な数を使ったベクトルとして $R, I, J$ と書き換えたものが本方程式である。回転を表す3つ目の成分を $K$ ではなく $R$ と表記するのは、単なる誤記ではなく、三四式独自の意味を持たせるための意図的な選択である。

四元数（クォータニオン）$q = w + xi + yj + zk$ と本方程式は、「実数1つ＋虚数的な数3つ」という**形式**を共有する。しかし意味は異なる。

| 観点 | クォータニオン | 三四式（$rR+iI+jJ$） |
| :--- | :--- | :--- |
| 役割 | 回転を合成する**演算子**（$i^2=j^2=k^2=ijk=-1$ の非可換な掛け算規則を持つ） | $X,Y,Z$ と同じく方程式に**足し算される成分** — 演算子ではなく記述的な次元 |
| 拘束 | 単位クォータニオンは $w^2+x^2+y^2+z^2=1$ に拘束され、自由度は3 | 現時点では拘束を課さず、$X,Y,Z$ と対等な独立3次元として扱う |
| 対象 | 3次元回転群 $SO(3)$ という厳密な数学的対象 | 「存在 $P$ がどちらを向いているか」を表す存在論的な記号 |
| 具体的な中身 | 抽象的な代数的単位（それ自体に意味内容はない） | $r,i,j$ はそれぞれ独立した性質に対応づけられる（[`02-dynamic-model.md`](02-dynamic-model.md) 参照：$r$=欲求・意志、$i$=関係性・共感、$j$=倫理・全体貢献） |

一言でいえば、クォータニオンから「実数＋虚数的3成分で方向を表す」という**器**だけを借り、中身（演算規則・拘束・成分ごとの意味）は三四式独自のものとして再定義している。$I, J$ がオイラーの公式（$e^{i\pi} = -1$、[`euler-connection.md`](../02_MATHEMATICS/euler-connection.md) 参照）に現れる虚数単位と同じ発想の延長にある点は、クォータニオンとも共通する系譜である。
