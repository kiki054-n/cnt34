# 定義集 — Definitions

*三四式（TTT理論）で用いる記号・用語の定義と、現在ひらいている未決項目の一覧。*

この文書は理論の**辞書**です。新しい主張はここでは行いません。各項目には、それが「決めごと」なのか「主張」なのか「まだ答えが出ていない問い」なのかを示すラベルを付けます。

---

## 0. ラベルの読み方

三四式では、すべての記述に**確からしさの水準**を付けます。同じ大きさの文字で書かれていても、地位は同じではありません。

| ラベル | 意味 | 反証できるか |
| :---: | :--- | :--- |
| **D** | **定義** — 「そう呼ぶ」と決めたもの。真偽を問えない | ✗（定義は間違えようがない。ただし「役に立たない」ことはある） |
| **A** | **借用** — 確立された数学・物理から借りたもの。**出典必須** | ✗（借用元がすでに検証済み。誤って借りていれば訂正の対象） |
| **B** | **命題** — 定義と借用から導けるが、まだ導出を書き下していないもの | ○（導出を書けば D+A に降りる。書けなければ C に落ちる） |
| **E** | **対応** — 現実の事例・観察との対応づけ | ○（対応しない反例を1つ出せば崩れる） |
| **C** | **仮説** — 主張だが、導出も検証もまだない | ○（これが理論の本体。ここを潰していくのが仕事） |
| **O** | **未決** — 問いとして開いている。答えを持っていない | — |
| **F** | **反証済み** — 誤りと確認されたもの。**消さずに残す** | 済 |

> **原則**: 構成の産物は発見ではない。定義から出てきたものを「導いた」と言わない。
> **原則**: 単位で変わる量は不変量ではない。
> **原則**: 後から黙って直さない。誤りは F として残し、訂正の履歴を書く。

### 1.3 方向の3次元 — 2つの表記

方向側の3成分には、本リポジトリ内に**2通りの表記**があります。**同じ3成分の別表記であり、別の量ではありません。**

| 表記 | 使う場面 | 出典 |
| :--- | :--- | :--- |
| $uU + vV + wW$ | 幾何学的な導入（双極から軸が生まれる話） | [`00-dual-pole.md`](00-dual-pole.md) §2 |
| $rR + iI + jJ$ | 各成分に具体的な意味を与える定式化 | [`01-basic-equation.md`](01-basic-equation.md) §1.1 |

$$P = xX + yY + zZ + uU + vV + wW \;=\; xX + yY + zZ + rR + iI + jJ$$

⚠️ **この等号の厳密な導出は未決です（[O-1](#o-1)）。** 現時点では「同じものを2通りに書いている」という宣言であって、証明ではありません。

各成分の意味づけ:

| 記号 | 意味づけ | 水準 | 出典 |
| :--- | :--- | :---: | :--- |
| $rR$ | 欲求・意志。内なる動機・目的、システムを駆動する一次エネルギー | **C** | [`02-dynamic-model.md`](../02_MATHEMATICS/02-dynamic-model.md) §1 |
| $iI$ | 関係性・共感。他者との結びつき、非線形な相互理解 | **C** | 同上 |
| $jJ$ | 倫理・全体貢献。全体への調和、使命感 | **C** | 同上 |

> **なぜ $K$ ではなく $R$ か**: 四元数の慣習は $i, j, k$ ですが、三四式は3つ目を $R$ と書きます。これは誤記ではなく意図的な選択です（[`01-basic-equation.md`](01-basic-equation.md) §1.2）。**D**

### 1.5 回転軸 π と単位条件

| 記号・式 | 定義 | 水準 |
| :--- | :--- | :---: |
| $\pi$ | 3軸を1つの構造として束ね、回転させて閉じる働き。$X,Y,Z$ のどれか特定の1軸ではない | **D** |
| $XYZ\pi = 1$ | 空間的な細胞（自律した1つの構造）が成立するための条件 | **C** |
| $OOO\pi = 1$ | エネルギー的な細胞が成立するための条件 | **C** |
| $e^{i\pi} = -1$ | オイラーの公式。双極の誕生として読む | **A**（数学）＋ **C**（読み方） |
| $e^{i \cdot 2\pi} = 1$ | 顕在化の周期として読む | **A** ＋ **C** |

> **「三」と「四」の数え方**: 名称の「4」は式の成分数ではありません。方向側の3軸に、それらを閉じる回転軸 $\pi$ を加えて「4」です。位置3軸＋方向3軸＝6成分、これに各系の $\pi$ を数えて「三と四」となります。**D**

## 2. この理論が主張していないこと

誤解を避けるため、明示的に否定しておきます。

| 誤解 | 実際 |
| :--- | :--- |
| 「TTTは四元数の一種である」 | ✗。「実数1つ＋虚数的な数3つ」という**形式**を共有するだけです。四元数は $i^2=j^2=k^2=ijk=-1$ という非可換な**演算子**ですが、$rR+iI+jJ$ は $X,Y,Z$ と同じく方程式に**足し算される成分**であり、演算子ではありません。$w^2+x^2+y^2+z^2=1$ のような拘束も現時点では課していません（[`01-basic-equation.md`](01-basic-equation.md) §1.2） |
| 「原子軌道との対応は物理法則の主張である」 | ✗。$p$軌道／$d,f$軌道との対応は**幾何学的発想の借用（アナロジー）**であり、量子力学に対する主張ではありません（[`02-dynamic-model.md`](../02_MATHEMATICS/02-dynamic-model.md) §1） |
| 「光速 $c$ を導出した」 | ✗。生成プロセスの上限速度が $c$ に一致する根拠は**まだ物語であり、数式による導出ではありません**（[`04-genesis-and-time.md`](../04_LIFE/04-genesis-and-time.md) §3、[O-5](#o-5)） |
| 「$XYZ\pi=1$ は定理である」 | ✗。仮説（**C**）です。πがなぜ3軸を閉じるのかの厳密な定式化は未決（[O-2](#o-2)） |

## 3. 未決項目 — いま空いている問い

**ここが、参加していただきたい場所です。** すべて、理論の内部文書が自ら「今後の課題」と書いている箇所を集めたものです。

<a id="o-1"></a>
### O-1. $U,V,W$ と $R,I,J$ の対応関係

**問い**: 回転座標 $(U,V,W)$ から虚数的表記 $(R,I,J)$ への書き換えの、数学的な根拠は何か。両者は同型か、それとも別の構造か。

**なぜ重要か**: この理論で最も基礎的な穴です。ここが決まらないと、同じ式に2つの読み方が併存したままになり、数値を出すたびに「どちらの目盛りで読むのか」が争点になります。

**決着のつけ方**: 対応写像を明示的に書き下し、それが全単射であることを示す。あるいは、そもそも同型ではないと示す（その場合、2つの表記を統合せず別物として分ける）。

**出典**: [`01-basic-equation.md`](01-basic-equation.md) §1.2 末尾

<a id="o-2"></a>
### O-2. πはなぜ3軸を閉じるのか

**問い**: $XYZ\pi = 1$ において、回転軸 $\pi$ が3軸を「閉じて単位1にする」という操作は、数学的にどのような演算か。

**決着のつけ方**: $X, Y, Z, \pi$ を要素とする代数構造を定義し、この積が定義される演算を書く。書けなければ、この式は式ではなく比喩であると認める。

**出典**: [`XYZ-pi.md`](../02_MATHEMATICS/XYZ-pi.md) 末尾

<a id="o-3"></a>
### O-3. 2つのπの非対称

**問い**: 位置側のπは「3軸の外側から閉じるだけの軸」だが、エネルギー側のπは「閉じる軸であると同時に第4のエネルギー（創造）そのもの」とされている。この非対称は、理論の必然か、それとも整理の未熟か。

**決着のつけ方**: 対称にできるなら、位置側にも第4の位置的な何かがあるはず——それが何かを言う。対称にできないなら、なぜ非対称でなければならないかを言う。

**出典**: [`OOO-pi.md`](../02_MATHEMATICS/OOO-pi.md) §2（「現時点では整理しきれておらず、今後の検討課題として残しておく」）

<a id="o-4"></a>
### O-4. 7節点・4辺は本当に自律形成されるか

**問い**: 「位置に方向の相互作用が加わると、系は自律的に安定したテンセグリティ構造を形成する」——これは本リポジトリの中心的な主張だが、導出も数値実験もまだない。

**決着のつけ方**: これは**実装で決着がつく唯一の項目**です。$N$ 個の点に規則を与えて時間発展させ、7節点・4辺の構造に収束するかを見る。そして必ず**帰無対照**（規則をランダム化したとき同じ構造に何％到達するか）を併記する。ランダムでも同じ割合で到達するなら、それは理論の成果ではありません。

**出典**: [`README.md`](../README.md)、[`00-dual-pole.md`](00-dual-pole.md) §3

<a id="o-5"></a>
### O-5. 上限速度が光速に一致する根拠

**問い**: 生成プロセス（Step 8 → Step 21）が到達する上限速度が、なぜ光速 $c$ と一致するのか。

**決着のつけ方**: 内部から $c$ の値を導く。導けないなら、$c$ は外部から借りた定数であると明記し、「導出した」という言い方を撤回する。

**出典**: [`04-genesis-and-time.md`](../04_LIFE/04-genesis-and-time.md) §3（「現時点ではまだ物語（ナラティブ）であり、数式による導出ではない」）

<a id="o-6"></a>
### O-6. $R,I,J$ に拘束を課すか

**問い**: 単位四元数は $w^2+x^2+y^2+z^2=1$ に拘束され自由度3になる。三四式は現時点で拘束を課していないが、課さないままでよいのか。課さないなら「方向」の大きさは何を意味するのか。

**決着のつけ方**: 拘束を課すか課さないかを決め、どちらの場合も物理的・意味論的な帰結を書く。

**出典**: [`01-basic-equation.md`](01-basic-equation.md) §1.2 の比較表
