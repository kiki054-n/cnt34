# 感謝の循環プロトコル（Gratitude Circulation Protocol）

> 「感謝は、4柱間を流れるエネルギーである。感謝が途絶えると、社会のテンセグリティは崩れる。」

---

## 原理

トリテトラ理論において、双極（00）が引き合うことで「線（辺）」が生まれる。
社会において、4つの柱の間を流れる**感謝**が、この「線」に相当する。

謝は単なる感情ではない。それは：

- **エネルギー**：労働の対価としての物質的還流（賃金、商品、サービス）
- **情報**：労働の価値としての認識的還流（称賛、評価、記録）
- **関係**：労働の連続性としての社会的還流（信頼、継続、推薦）

この3層の還流が揃ったとき、感謝は「7節点4辺の曲面」として機能し、社会の構造を安定させる。

---

## 4柱間の感謝マトリクス

| 還流元＼還流先 | 第1柱・作る | 第2柱・支える | 第3柱・管理 | 第4柱・創造 |
|--------------|------------|--------------|------------|------------|
| **第1柱・作る** | — | 食と住を分かち合う | 基盤を提供する | 余裕を生み出す |
| **第2柱・支える** | 命を養う感謝 | — | 安全網を強化する | 物語を還元する |
| **第3柱・管理** | 秩序を守る感謝 | 尊厳を守る感謝 | — | 自由を保障する |
| **第4柱・創造** | 意味を更新する | 癒やしを与える | 視点を正す | — |

---

## 感謝の作法

### 1. 感謝は具体的である

「ありがとう」では不十分。感謝は、**どの柱のどの行為に対して、どのエネルギーが還流したか**を具体的に記述する。

> 例：「第1柱の農家の方々が作った米で、第2柱の介護現場で命を養っています。その食で、今日も創造の軸が回っています。」

### 2. 感謝は双方向である

感謝は一方通行では循環しない。受け取った者は、別の柱へ感謝を還流する責任がある。

### 3. 感謝は記録される

感謝は `contrib/gratitude-log/` に記録される。記録された感謝は、リポジトリの「エネルギー蓄積」として可視化される。

### 4. 感謝が閾値を超えると顕在化する

蓄積された感謝が一定の閾値を超えると、新しいプロジェクト（細胞分裂）が生まれる。
これは「入りきれなかった感謝が、新しい境界を作る」ことに相当する。

## GitHubでの実装

### Issueテンプレート「感謝を送る」

```yaml
name: 感謝を送る
about: 他の柱の貢献に謝を送る
title: "[Gratitude] 〇〇柱の□□さんへ"
labels: ["gratitude"]
body:
  - type: dropdown
    id: from-pillar
    attributes:
      label: 送り元の柱
      options:
        - 第1柱・作る労働
        - 第2柱・支える労働
        - 第3柱・管理労働
        - 第4柱・創造労働
  - type: dropdown
    id: to-pillar
    attributes:
      label: 送り先の柱
      options:
        - 第1柱・作る労働
        - 第2柱・支える労働
        - 第3柱・管理労働
        - 第4柱・創造労働
  - type: textarea
    id: message
    attributes:
      label: 感謝の言葉
      description: 具体的な行為と、それがもたらしたエネルギーを記述してください
  - type: textarea
    id: energy
    attributes:
      label: 還流したエネルギー
      description: 物質的・情報的・関係的な還流があれば記述してください
```

## 感謝ログのフォーマット

```
contrib/gratitude-log/
├── 2026/
│   ├── 2026-08/
│   │   ├── 2026-08-23_pillar01-to-pillar02.md
│   │   ├── 2026-08-23_pillar04-to-pillar01.md
│   │   └── ...
│   └── ...
└── README.md
```

各ログファイルのテンプレート：

```markdown
# Gratitude Log — YYYY-MM-DD

## From: [第〇柱・□□労働]
## To: [第〇柱・□□労働]

### 感謝の言葉
（具体的な記述）

### 還流したエネルギー
- 物質的還流：（例：食料の提供、製品の寄付）
- 情報的還流：（例：称賛、評価、記事の執筆）
- 関係的還流：（例：紹介、継続的な協力の約束）

### 署名
- 送り主：@username
- 日時：YYYY-MM-DD HH:MM
```
