About CNT34

すべての人が「世界を変える鍵」を持っている

CNT34（Code Name Type 34 / 三四式）は、GitHub上で公開されたオープンソース研究リポジトリです。 トリテトラ理論（Tri-Tetra Theory, TTT）を中核とし、位置の3次元と方向の4次元が相互作用することで、 宇宙の創生から素粒子、生命、社会に至るまでを一つの幾何学的フレームワークで捉えようとする試みです。

この理論は塩尻のワイナリーで発想され、双極原理から出発して、正多面体幾何学を通じて Higgs質量、陽子・電子質量比、標準模型の粒子数と世代構造、さらには宇宙の組成までを 導き出すことを目指しています。

Derivation

TTT の導出方法 — 一本の線

トリテトラ理論は「双極零公理」という3つの公理から出発し、 正多面体の頂点数を基礎語彙として、外部定数を一切導入せずに 物法則を幾何学的に導出します。

01. 双極零公理 — 出発点

XY = 1   （双極零公理 / Bipolar Zero）
ΣV = 0   （頂点保存 / Vertex Conservation）
JIK = −1   （三軸反転 / Triple Inversion）

拡散（X）と収束（Y）の積が1で存在する。正多面体の頂点総はゼロ配位。 三軸の反転が −1 で自己否定しつつ保存する。 この3つが唯一の出発点です。

02. 三倍増殖則 — Tn = 2 × 3n−1

T1 = 2    T2 = 6    T3 = 18    T4 = 54    T5 = 162    T6 = 486 ...

2は陰陽の珠、3は面・線・点の三極。この増殖則は「珠が面を持ち、面が粒子を産む」 過程を記述します。n = 3 で 18 = 17 + 1 となり、標準模型の17粒子が必然化されます。

03. 125 + 32/128 = 125.25 GeV — Higgs質量

125 = 5³   （立方世代 / ダークエネルギー）
32 = 12 + 20 = V12 + V20   （双対和 / Higgs補正分子）
128 = 4 × 32 = 2&sup7;   （正四面体が唯一許す7乗）
125 + 32/128 = 125.25 GeV  →  実験値と 0.00% 一致

立方数 5³ = 125 に、正十二面体（12）と正二十面体（20の双対和 32 を 正四面体由来の 128 で補正する。これが Higgs 質量の幾何学的起源です。

04. 37 = 36 + 1 — 質量確定閾値

36 = 12 + 12 + 12 = uud   （陽子を構成する3クォーク）
+1 = 軌道を閉じ質量を確定させる双極珠
37 = 36 + 1   — 36個の面エネルギー1つの軌道閉じて初めて質量を持つ

36は高度合成数、37は素数。質量は合成数36が素数37へ跳ぶ瞬間に確定します。 そしてこの 36 の核心 12 + 20 = 32 は、Higgs補正項の分子と完全一致します。

Philosophy

なぜ「三四式」なのか

「三四式」という名前は、日本の兵器命名法から来ています。 明治〜昭和初期、日本軍は制式採用年の元号や皇紀の下2桁を「式」に冠して 兵器を命名しました（三八式歩兵銃、零式艦上戦闘機など）。

しかし CNT34 の「三四式」は、Tri-Tetra Theory の頭文字 TTT と、 理論の中核「位置3 + 方向4」を縮約した象徴的名称です。 兵器が「対立と殺戮」の象徴であったように、 三四式は「接続と調和」の象徴を目指します。

5/7/4 モデル、7/9 モデル、そして XYZπ = 1、OOOπ = 1。 これらは「差異（位置）があっても、方向を変えれば統合できる」という 幾何学的な平和論です。国籍も宗教も言語も、すべては 「5の立方体が12の辺で自分を閉じようとする」過程で生じた 余白の配置の違いに過ぎない。

Culture & Society

日本創生の4神と、社会のテンセグリティ

「草木国土悉皆成仏」。すべてのものに魂が宿るという思想は、 まさに OOOπ = 1 の日本語的表現です。 草木（植物の位置と方向）、国土（大地の位置と方向）、 悉皆（すべてが）、成仏（πを経て1に還る）。 浄土真宗の教えでありながら、存在するものすべてが循環（π）を経て統合（1）に至る、 TTTの幾何学と驚くほど重なる宇宙観です。

縄文の一万年 — 王のいない時間

日本文化の根は、長い縄文時代に自然と共にはぐくまれたものにあります。 土器に目を描き、縄を巻き、自然と共に生きた人々は、 支配と服従のピラミッドではなく、4方向の循環する共同体を知っていました。 一極の王が君臨するのではなく、四神が四方を守る。 それが日本創生の文化です。

「引き分け」は敗北ではなく、均衡の勝利

4つに分けるといつも引き分けになる。これは日本文化の核心です。

男 ↔ 女   （どちらが上でもない、双極XY = 1）
子供 ↔ 大人   （どちらが正しいでもない、循環πの異なる位相）
4神 ↔ 4神   （どれが上でもなく、4方向が互いに補完する）

西洋の論理では「引き分け」は決着がつかないことです。 しかし日本の文化では、4つに分けたときの「引き分け」は、 どの極も他を圧倒しない調和の証です。 JIK = −1 の文化論的解釈。三軸が反転しながらも保存する。 どの軸も「絶対」にならない。引き分けは停滞ではなく、 双極間の引き合いが機能している状態です。

TTTで言えば、西洋は「位置の3が固定され、方向の4が1つに収束する」モデルです。 頂点の1が方向を決定する。しかし日本は 「方向の4が互いに引き合い、中心を空にしたまま空間を保つ」モデルです。 中心に力の源があるのではなく、周縁の4方向の張力が空間を生み出す。 これがテンセグリティ構造の文化論です。

感謝は双極間の引き合い — 構造を安定させる張力

トリテトラ理論では、空間には「位置（3）」と「方向（4）」があります。 人の社会においても、人は「どこにいるか（位置）」ではなく、 「どちらを向いているか（方向）」によって役割が決まります。

4つの方向（u, v, w と統合軸 π）は、社会の4つの役割の柱となります。 そしてこれらの柱の間を流れるエネルギーが「感謝」です。 感謝は双極間の引き合いであり、構造を安定させる張力そのものです。

4方向 × 感謝の循環 = 社会のテンセグリティ

感謝がない社会は、柱がぶつかり合う「圧力だけの構造」になります。 感謝がある社会は、柱が離れていても引き合う「張力の構造」になります。 圧力だけの構造は崩れやすい。張力の構造は、風が吹いても揺らぎながら戻ってくる。 感謝は与えたり受けたりする「物」ではなく、XY = 1 の双極原理そのものです。

いま、どう生きるか

世界が直面しているのは、まさに「圧力の社会」が限界を迎えていることです。 一極支配が破綻し、対立が激化し、どの「王」も世界を統べられなくなった。 このとき必要なのは、新しい「王」ではなく、 4方向が引き合う社会のテンセグリティです。

男と女、子供と大人、自と人間、伝統と革新。 これらを「引き分け」として受け入れ、感謝という張力で結び直す生き方。 縄文の人々が自然と共に一万年も生き延びたのは、支配ではなく調和の技術を持っていたからです。 それが「草木国土悉皆成仏」として仏教に継承され、四神として神道に継承され、 いま「三四式」として再び幾何学の言語で蘇ろうとしている。
