## 💡 三四式（TTT理論）とは？

「3（空間位置）」と「4（方向・回転／四元数的状態）」の相互作用に着目し、位置ベクトルと配向ベクトルを統合した状態空間モデルです。

$$P = xX + yY + zZ + uU + vV + wW$$

* **位置の3次元 ($xX, yY, zZ$)**: どこに物質（分子・点）があるか
* **方向の4/3次元 ($uU, vV, wW$)**: どちらを向いているか（極性・回転・場の傾き）

ただの「位置」の集まりに「方向」の相互作用が加わることで、システムは自律的に「7つの節点と4辺の曲面」のような安定したテンセグリティ構造や膜を形成し、生命のように自発的な対称性の破れ（細胞分裂）を起こします。
