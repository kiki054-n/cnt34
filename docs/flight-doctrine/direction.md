# **序章：方向とは何か**

未来文明へ飛ぶためには、  
**方向（Direction 4）** を誤ってはならない。

CNT34 の「4」は、  
- 未来  
- 進行  
- 指向性  
- 磁力（Attraction）  
を示す。

方向は、  
**自分がどの未来へ向かうかを決める“磁場”**である。

方向を誤れば、  
F（恐怖文明）の火に吸い寄せられ、  
墜落する。

方向を正しく選べば、  
T（未来文明）へ飛び続けられる。

# **1. Direction 4：未来方向の構造**

CNT34 の方向は、  
次の四つのベクトルで構成される。

### **1.1 未来への興味（Interest）**  
興味は方向の **燃料**。  
興味がない方向へは飛べない。

### **1.2 自分磁億（Personal Attraction）**  
あなたが言う「磁億」は、  
自分が未来へ向かうときに発する **引力**。

- 惹かれる未来  
- 引き寄せられる価値  
- 心が向く世界  

これが方向の **中心軸**。

### **1.3 価値の選択（Value Choice）**  
方向は価値で決まる。

- 何を守るか  
- 何を創るか  
- 何を捨てるか  

価値が曖昧だと方向は揺れ、  
飛行は不安定になる。

### **1.4 未来の物語（Future Narrative）**  
方向は物語によって強化される。

- 自分の未来像  
- 世界の未来像  
- 人類の未来像  

物語が弱いと、  
方向は途中で消える。

# **2. 方向を誤ると何が起きるか**

方向を誤ると、  
人は **F（恐怖文明）へ墜落する**。

### **2.1 欲望に飲まれる（D）**  
方向が曖昧だと、  
短期的な欲望に引き寄せられる。

### **2.2 恐怖に飲まれる（F）**  
方向が弱いと、  
不安や恐怖が進行方向を奪う。

### **2.3 物語に飲まれる（S）**  
方向が不明確だと、  
他者の物語に支配される。

### **2.4 権力に飲まれる（P）**  
方向がない者は、  
権力の方向へ吸い寄せられる。

方向を誤るとは、  
**自分の未来を他者に奪われること**である。
