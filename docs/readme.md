TTT Repository Architecture
4つの柱と感謝の循環
三四式理論を使い、人の役割を4つの方向として定義し、
感謝をエネルギーの循環として設計する

01 / 原理
4方向は4つの柱となる
トリテトラ理論では、空間には「位置（3）」と「方向（4）」がある。 人の社会においても、人は「どこにいるか（位置）」ではなく、 「どちらを向いているか（方向）」によって役割が決まる。

4つの方向（u, v, w と統合軸π）は、社会の4つの役割の柱となる。 そしてこれらの柱の間を流れるエネルギーが「感謝」である。 感謝は双極間の引き合いであり、構造を安定させる張力そのものだ。

4方向 × 感謝の循環 = 社会のテンセグリティ
