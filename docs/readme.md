CNT34 の文明モデルを 「実際に使える形」へ変換するための飛行マニュアルである。
CNT34 は構造として美しいが、構造だけでは未来文明へは到達できない。
その構造を 人間の行動・学び・方向選択・倫理・到達へ変換する必要がある。
その変換装置が flight-doctrine だ。

1. CNT34 の “行動化レイヤー” としての flight‑doctrine
CNT34 は

Position（3）＝自分の軸

Direction（4）＝自分磁億

π（回転）＝離陸の点火

という 未来文明の構造式である。

しかし構造式は「理解」には使えても、
「未来へ飛ぶ行動」には直接つながらない。

そこで CNT34 の構造を
Launch → Direction → Learning → Ethics → Arrival  
という 人間が実際に踏むステップへ変換したものが flight‑doctrine。

Docs に置く理由は、
CNT34 を 概念から行動へ橋渡しする公式ルートだから。

2. CNT34 の “起動プロトコル” を担う
CNT34 は文明モデルであり、
そのままでは「起動」しない。

起動には

離陸条件

方向の設定

学びの燃料

倫理の安全装置

到達の構造

が必要になる。

これらを体系化したのが flight‑doctrine。
つまり flight‑doctrine は CNT34 の 起動プロトコル（起動手順書）である。

Docs に置くことで、
CNT34 を使う人は 必ず起動プロトコルを通ることになる。
