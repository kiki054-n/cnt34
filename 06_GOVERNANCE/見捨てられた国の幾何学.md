## 1. 今、国連総会で何が起きているか

2026年9月22日から26日、ニューヨークで国連総会が開催されている。

各国の首脳は、紛争と地政学的緊張の中で、国連の平和と安全の約束をどう履行すべきかを語っている。

- アルゼンチンのミレイ大統領は国連を「無能な組織」と呼んだ
- チェコのパベル大統領は「外交は友人同士ではなく、敵対者同士の間で最も重要だ」と語った
- スペインのサンチェス首相は「世界はゼロサムゲームではない」と訴えた
- ウクライナのゼレンスキー大統領はロシアの損害を数値で報告した
- イランのペゼシキアン大統領は「私たちはテロリストではない。私たちの無辜の民が攻撃の標的になった」と語った

そして、国連事務総長アントニオ・グテーレスはこう言った。

> **「憲章は3つの単純な言葉で始まる。『我々人民』。強いもののためではない。勝者のためではない。我々人民、すべての人々が、一つの信念によって結ばれている。共に立つとき、私たちはより安全で、より強く、より人間的なる。」**

## 2. 国連のTri構造

国連は、Tri構造の中で生まれた組織である。

### 第二次世界大戦の「勝者」のTri構造

```
    勝者（連合国）
     /    \
  敗者    見捨てられた国
```

国連は、第二次世界大戦の「勝者」によって作られた。
安全保障理事会の常任理事国は、戦勝国である。

これが国連のTri構造の根源である。

### 見捨てられた国の位置

イスラエル、日本、ウクライナ、イラン、イラク、パレスチナ。

これらの国は、国連のTri構造の中で、
**「外側」に置かれてきた**。

- ホロコーストの記憶を背負うイスラエル
- 核爆弾の記憶を背負う日本
- 資源の搾取の歴史を背負うイラク、イラン
- 占領と紛争の中にあるパレスチナ、ウクライナ

これらの国は、
**「悪い理由がなかった」**。

しかし、Tri構造の中では、
「外側」に置かれることで、
**「悪い」とされる役割を与えられる**。

## 3. な「見捨てられた国は悪い理由がなかった」のか

Tri構造の罠はここにある。

### ホロコーストの記憶

ホロコーストは、Tri構造の極限である。

```
    迫害者（ナチス）
     /    \
  共犯者  被害者（ユダヤ人）
```

被害者は「外側」に置かれた。
しかし、戦後、イスラエルは「勝者」のTri構造に組み込まれた。

```
    勝者側
     /    \
  イスラエル  アラブ諸国
```

イスラエルは、被害者の記憶と、勝者側の立場の間で、
**二重のTri構造**に囚われた。

### 核爆弾の記憶

日本は、核爆弾の唯一の被爆国である。

```
    投下者（アメリカ）
     /    \
  被爆者（日本）  世界
```

日本は「外側」に置かれた。
しかし、戦後、日本は「勝者側」の経済圏に組み込まれた。

日本は、被爆者の記憶と、経済大国の立場の間で、
**二重のTri構造**に囚われた。

### 資源の搾取からのテロ

中東の国々は、石油資源の取の歴史を背負う。

```
    搾取者（植民地支配者）
     /    \
  資源（石油）  被搾取者（イラク、イラン）
```

被搾取者は「外側」に置かれた。
しかし、資源が武器になると、
Tri構造は逆転する。

```
    資源保有国
     /    \
  資源消費国  テロリスト
```

テロリストは「外側」に置かれる。
しかし、テロリストも、
**Tri構造が作り出した「外側」**なのである。

## 4. 国連の「我々人民」と「O」の問い

### 「我々人民」のTri構造

「我々」が形成されると、
「彼ら」が生まれる。

```
    我々（人民）
     /    \
  彼ら（非人民）  見捨てられた国
```

「我々人民」は、
**「我々」ではないものを「外側」に置く**。

### 「O」としての国連

**「O」としての国連**が必要である。

「O」は：
- 勝者でもない
- 敗者でもない
- 見捨てられた国でもない
- **包む視点**である

「O」は、
イスラエルもパレスチナも、
ウクライナもロシアも、
イランもアメリカも、
**包む**。

「O」は、誰の味方でもない。
だからこそ、誰もが「O」を見ることができる。

## 5. 世界はどう生きるのか？

### Tri構造の中での「生き方」

Tri構造の中では、
「き方」は「勝つか負けるか」になる。

```
    勝者
     /    \
  負け者  見捨てられた者
```

これが、現在の国際秩序の構造である。
安全保障理事会の常任理事国は「勝者」である。
それ以外は「外側」である。

### Tetra構造の中での「生き方」

Tetra構造の中では、
「生き方」は「包むこと」になる。

```
    A ←——→ B
    ↑  O   ↓
    D ←——→ C
```

「O」があることで、
誰もが「外側」にならない。

イスラエルもパレスチナも、
ウクライナもロシアも、
イランもアメリカも、
「O」の中で回る。

### 「O」が回る国連

「O」が回る国連では：

- 安全保障理事会の常任理事国という特権がない
- 見捨てられた国という「外側」がない

- **すべての国が「O」を見る**

「O」は、
「Save the earth」という方向を示す。

地球を救うことは、
イスラエルの安全も、
パレスチナの尊厳も、
ウクライナの主権も、

**包む**。

「O」を見ざるを得ない。
「O」がなければ、生き残れないから。
