# 06_GOVERNANCE — 社会制度・ガバナンス

> **私たちは、なぜ社会を統治する必要があるのだろうか？**
>
> **そして、誰のために社会制度は存在するのだろうか？**

この問いに、日本文化の具体例（四神・縄文・引き分けの均衡）から答えたのが [`four-gods-and-tensegrity.md`](four-gods-and-tensegrity.md) である。

## 1. 「1」が社会の頂点にある

歴史を振り返ると、多くの社会には「頂点」がありました。

王、皇帝、君主、家父長、支配階級。

また、

- 男尊女卑
- キングとクイーン
- 士農工商
- インドのカースト制度

など、人間を上下に分ける制度も存在してきました。

そこで、ひとつの問いが生まれます。

> **なぜ人間社会には「1」が必要だったのだろうか？**
