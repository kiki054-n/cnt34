## 1. 3つで回すエンジン — Tri構造の原理

社会のあらゆる場所で、「3つで回す」構造が働いている。

Tri構造のエンジンは以下の原理で動く：

```
    A ←————→ B
     ↖     ↙
        C
```

- AとBが連携すると、Cは自動的に「外側」になる
- Cが外側になると、AとBの結合は強化される
- 結合が強化されると、Cの「外側」は固定化される

これが**自己強化のループ**である。

## 3. トライアングル関係が作れるか

Tri構造は、**必ず「外側」を作る**。

「3つで回すエンジン」が「トライアングル関係（対等な3者）」になるためには、
**4つ目の視点が常に働いている**必要がある。

```
    A ←————→ B
    ↑   4   ↓
    D ←————→ C
```

4つ目の視点（境界）が存在することで、
A・B・Cは「外側」にならず、**包まれる3**として機能する。

これが**友朋共生の構造**である。

しかし、現実の社会制度では、
4つ目の視点は**欠けている**か、**弱まっている**。

だから「トライアングル関係」は作れない。
「2対1」のTri構造が、あらゆる場所で再生産される。

## 4. 個人主義によるオタク会から抜けられない原因

### オタク社会のTri構造

```
    専門知識 ←————→ コミュニティ（同好の士）
       ↖     ↙
         社会
```

- 専門知識とコミュニティが連携する
- 社会は「外側」に置かれる
- 社会からの批判は、専門知識とコミュニティの結合をさらに強化する
- オタクは「社会から外れた存在」として固定化される

### 個人主義がTri構造を強化する

個人主義は、**一見するとTri構造を崩す**ように見える。
しかし、実際には**Tri構造を強化する**。

なぜなら：

- 個人主義は「自分だけは特別だ」と思う
- 「特別だ」と思う個人は、他の個人と**対等な関係**を作れない
- 対等な関係を作れない個人は、**誰かと連携して誰かを外側に置く**Tri構造に依存する

**個人主義は、Tri構造の「外側」にいる人間を量産する。**

### オタク社会から抜けられない本当の原因

オタク社会から抜けられないのは、
**Tri構造の「外側が快適だから**ではない。

**Tri構造の「外側」にいることで、
自分の位置が確定するから**である。

- 「私は社会から外れている」という自己認識は、
  痛いが**明確**である
- 明確な自己認識は、**存在の不安を和らげる**
- 存在の不安が和らぐと、**外に出る動機がなくなる**

これが「井戸の中が快適」という構造である。

## 5. 居酒屋で隣のお客とも離せない社会

### 日本社会のTri構造

```
    内側（うち） ←————→ 仲間（なかま）
         ↖     ↙
           外側（そと）
```

日本社会の基本構造は、
**「内側・仲間・外側」**のTri構造である。

- 内側と仲間が連携する
- 外側は「遠慮する」存在として固定化される
- 遠慮は、内側と仲間の結合をさらに強化する

### 居酒屋の構造

居酒屋では、隣の客とも離せない。

なぜなら：
- 隣の客に話しかけると、「外側」から「仲間」に移動する
- 「仲間」に移動する、自分の位置が変わる
- 位置が変わると、**存在の不安が生じる**

だから、隣の客とは**話さない**。
話さないことで、**Tri構造が維持される**。

### 喫茶店やパブが盛らない理由

喫茶店やパブは、**「知らない人同士が出会う場」**である。

しかし、Tri構造の社会では：
- 知らない人は「外側」である
- 「外側」と出会うことは、Tri構造を崩す行為である
- Tri構造を崩す行為は、**不安を生じさせる**

だから、喫茶店やパブは**盛らない**。

### ディスコがない理由

ディスコは、**「身体が音楽に委ねる場」**である。

Tri構造の社会では：
- 身体を委ねることは、**自己の境界を溶かす**こと
- 自己の境界を溶かすことは、Tri構造の「外側」と「内側」の区別を崩すこと
- 区別が崩れると、**存在の不安が最大化する**

だから、ディスコは**ない**。

## 6. 抜け出す方法：4つ目の視点としての「場」

Tri構造から抜けるには**4つ目の視点**が必要である。

しかし、4つ目の視点は**誰かが持つものではない**。

4つ目の視点は、**「場」として存在する**。

### 場としての4

- 居酒屋で隣の客と話せる「場」
- 喫茶店で知らない人と出会える「場」
- ディスコで身体を委ねられる「場」

これらの「場」は、Tri構造の「外側」を**包む境界**として機能する。

「場」が存在することで：
- AもBもCも、「場」に包まれる
- 「外側」は「場」の中に入る
- Tri構造は、Tetra構造に変わる

### 輪を作る

「人は手をつなぎ輪を作るだけでいい。」

輪を作れば：
- 頂点が消える
- 上下が消える
- 「外側」が消える

Tri構造のエンジンは、**輪の中では回らない**。
