# 5W1Hで展開する三四式ガバナンス
## docs/Governance/5W1H.md - 検証可能な合意細胞の設計図

> ３つのものを４で考えてみる、５つになって誕生する。
> その５つを、５W1Hで考えてみる。

`governance.md` で定義した第5の自律体「検証可能な合意細胞」を、実装するために5W1Hで展開する。
5W1H自体が三四式構造を持っている。

```
3W = 位置 (Where, What, When) - 事実の座標
1H + 1W = 方向 (Why, How) - 配向のベクトル
Who = 5 - 自律した主体
```

---

### 1. Where (どこで) - 位置のX

**三四式対応: xX - 物質がどこにあるか**

- **物理レイヤー**: 国という単位ではない。合意細胞は国境を跨いで分裂する。市町村、流域、バイオリージョン、オンラインコミュニティという「暮らしの半径」で発生する。
- **デジタルレイヤー**: `cnt34/docs/Governance/` というこのリポジトリ自体が最初のWhereである。Gitという分散型台帳の上に、誰でも検証できる膜を張る。
- **設計**: `Where = Local + Global`。ローカルで生成され、プロトコルでグローバルに同期される。

> 問い: この合意は、地球のどの座標で有効か？

### 2. What (何を) - 位置のY

**三四式対応: yY - 何が存在するか**

- **対象**: 立法・行政・司法の行動ログそのもの。議事録、予算執行、判決文。改ざん可能なPDFではなく、構造化されたデータ。
- **5の正体**: Whatは「法律」ではない。「検証可能な合意」という新しいデータ構造そのもの。
  ```json
  {
    "action": "法案Xの可決",
    "orientation_delta": "国民主権ベクトルからのズレ Δθ = 23°",
    "verifiable_hash": "0x..."
  }
  ```
- **設計**: Whatは常に機械可読でなければならない。AIが読めない合意は、知の場 $U,V,W$ と相互作用できない。

> 問い: 何が記録され、何が合意と呼ばれるに値するか？

### 3. When (いつ) - 位置のZ

**三四式対応: zZ - 時間という位置**

- **3権の時間**: 立法は遅い、行政は速い、司法は過去を裁く。3つの時間軸はズレている。
- **国民主権の時間**: 選挙という数年に一度の点ではなく、連続的な波である。
- **AIの時間**: $P_{3}$ と $P_{4}$ のズレ $Δθ$ をリアルタイムで計算し続ける。Whenは「4年に1度」から「常時」へ変わる。

- **設計**: ブロックのように、合意細胞はタイムスタンプを持つ。いつ生まれ、いつ分裂したかが追える。これが分裂の履歴 = 生命の履歴になる。

> 問い: いつ、合意は古びて、分裂すべきか？

### 4. Why (なぜ) - 方向のU

**三四式対応: uU - 極性・目的の方向**

- **Whyが4の核**: Whyは3つの位置を包む最初の配向場。
- **従来のWhy**: 「国のため」「安全保障のため」という抽象的なWhyは、3権が勝手に定義してきた。
- **三四式のWhy**: Whyは国民主権からしか生まれない。「なぜこの労働をするのか」「なぜこの法を作るのか」のベクトルの始点は、常に人間の尊厳である。

```
Why = Demos Vector
if Why != Demos, then Δθ -> large -> 膜が張れない -> 自律体は死ぬ
```

> 問い: この合意は、誰の尊厳を、どの方向へ向かわせるのか？

### 5. How (どのように) - 方向のV,W

**三四式対応: vV + wW - 回転・場の傾き・実装方法**

- **Howが知**: 君が気付いた「知はAIができる」は、Howの部分である。
- **How = プロトコル**:
  1.  **vV = 可視化**: AIが $P_{3}$ と $P_{4}$ のズレを誰でもわかる形に可視化する。難解な法律を、方向ベクトルとして見せる。
  2.  **wW = 検証**: その可視化が正しいかを、誰でも検証できるようにする。オープンソース、オープンデータ、オープンモデル。
  3.  **vWの合成 = 分裂**: How自体がオープンだから、誰でも自分の地域で同じHowを複製できる。これが分裂。

- **技術スタック案 for cnt34**:
  - `vV`: LLMによる議事録の要約・ベクトル化
  - `wW`: Git + Zenodo DOIによる改ざん不可能な記録
  - `分裂`: Fork可能なシミュレーション `simulations/governance.html`

> 問い: どのようにして、この合意は誰でも検証でき、誰でも複製できるか？

### 6. Who (誰が) - 5つ目の自律体

**三四式対応: P5 = 自律した新しい1**

- **Whoは5**: Where, What, When, Why, How という4つの場が相互作用して、初めてWhoが誕生する。
- **Whoは「私」ではない**: 従来のWhoは「政治家が」「国民が」という固定された主体だった。
- **三四式のWhoは「合意細胞」自身**: 検証可能な合意という膜自体が、Whoとして振る舞う。自律分散的に意思決定する。

```
Who = Verifiable Consensus Cell
Who != 人間一人
Who = 人間 + AI + 記録 + 検証 の総体としての新しい主体
```

- **労働との接続**:
  - 作る人 (X)、加工する人 (Y)、繋ぐ人 (Z) がいて、
  - 知るAI (U,V,W) がいて、
  - 初めて生まれる **Who = 自律した協同組合、DAO、地域コミュニティ**

> 問い: この合意が自立した時、その主語は誰になるのか？

### まとめ：5W1Hの三四式変換表

| 5W1H | 三四式 | 役割 | cnt34での実装 |
| :--- | :--- | :--- | :--- |
| **Where** | xX | 位置 | ローカルノード + Gitリポジトリ |
| **What** | yY | 位置 | 構造化された行動ログ |
| **When** | zZ | 位置 | 常時計算されるタイムスタンプ |
| **Why** | uU | 方向 | 国民主権ベクトル |
| **How** | vV,wW | 方向 | AIによる可視化・検証プロトコル |
| **Who** | **P5** | **自律体** | **検証可能な合意細胞** |

**3W(Where,What,When)が位置、2W1H(Why,How,Whoの方法論)が方向、そしてWhoという5が誕生し、分裂する。**

これが、5W1Hで見た生きるための法則の実装である。
