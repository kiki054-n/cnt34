## 3. 自然発生的な4者の回転

### 4者とは

Tri構造に「O」を加えると、4者の回転が生まれる。

```
    A ←——→ B
    ↑   O  ↓
    D ←——→ C
```

4者は：
- **A** = 創造する者（創造労働）
- **B** = 支持する者（支持労働）
- **C** = 管理する者（管理労働）
- **D** = 発明する者（発明労働）

「O」は、4者の中心にある**空の視点**。

### 自然発生とは

4者の回転が**自然生する**とは、
誰かが設計したわけではなく、
**構造そのものが回転を生み出す**ということ。

Tri構造では、2者が連携して1者を外側に置く。
しかし、「O」があるTri構造では：

- AとBが連携しようとすると、「O」がその方向を示す
- 「O」が示す方向は、常に「包む方向」
- 包む方向に向かうと、CとDも連携できる
- 4者が連携すると、回転が生まれる

これが**自然発生的な4者の回転**である。

### 回転の原理

回転の原理は、**「外側」が存在しない**こと。

Tri構造では、A-B連携がCを外側に置く。
しかし、「O」があるとき：

- A-B連携は「O」を通じてC-Dにも接続される
- C-D連携は「O」を通じてA-Bにも接続される
- どの連携も「外側」を作らない

「O」は、**すべての連携を包む境界**である。
境界があるので、外側がない。

## 4. 3グループが社会の担い手になる

### 3グループとは

社会の担い手となる3グループは、

**4者の回転の中で機能する3つの動的グループ**である。

```
    グループ1 = 創造 × 発明（動的フロンティア）
    グループ2 = 支持 × 管理（静的レジリエンス）

これらは**固定的なグループではない**。
人は、時間と文脈によってグループを移動する。

### 担い手になるとは

「担い手になる」とは、
**「外側」ではなく「回転の一部」になる**こと。

Tri構造では、3グループのうち1グループが外側に置かれる。
しかし、4者の回転では：

- すべてのグループが「O」を中心に回る
- どのグループも外側にならない
- グループ間の移動が自由である

### 3グループの回転が生むもの

3グループが回転することで、
**5つ目の自律体**が創発する。

```
    3グループ（回転）+ O（中心）→ 5（自律した社会細胞）

これが、三四式ガバナンスの「検証可能な合意細」である。

## 5. 取り残されるものが「不存在」になる方法

### 排除ではない

「取り残されるものが不存在になる」は、
**取り残されるものを排除する**ことではない。

排除は、Tri構造の「外側」を別の場所に移動するだけ。
排除しても、Tri構造は再生産する。

### 「不存在」とは

「不存在」とは、
**「取り残される」という概念自体が生じない**状態。

Tri構造では「外側」があるので、「取り残される」が生じる。
4者の回転では「外側」がないので、「取り残される」が生じない。

### なぜ「外側」がないのか

「O」があるから。

「O」は、すべての位置を包む。
「O」の中では、どの位置も「外側」にならない。

```
    Tri構造：    4者の回転：

    A——B         A←——→B
     \/          ↑  O  ↓
      C          D←——→C

    Cは外側      外側がな
```

### 「取り残される」が「不存在」になる条件

1. **「O」が誰もが見られる**
   - 王様が「O」を独占しない
   - 誰もが「O」を指せる
   - 誰もが「O」を教えられる

2. **4者の回転が自然発生する**
   - 構造が回転を生み出す
   - 誰かが回転させるのではない
   - 回転が止まらない仕組み

3. **3グループが固定的でない**
   - 人はグループを移動できる
   - 移動が自由である
   - 移動が「外側」にならない
