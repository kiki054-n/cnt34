# 空間単位系 — Spatial Unit System

*理論ドキュメント — [`00-dual-pole.md`](00-dual-pole.md) から分岐する、「位置」側の単位系。*

## 0. 位置づけ

双極（00）が引き合って次元が生まれるとき、そのうち「どこにあるか」を担うのが空間の3次元 X, Y, Z である。「どちらを向いているか」を担うエネルギー・方向側の単位系は [`OOO-pi.md`](OOO-pi.md) が担当する。両者は対になっており、片方だけでは系は閉じない。

$$P = \underbrace{xX + yY + zZ}_{\text{位置（本稿）}} + \underbrace{uU + vV + wW}_{\text{方向（→ OOO-pi.md）}}$$

## 1. 3つの軸 — X, Y, Z

* **X**: どちらか一方の極から、もう一方の極へ向かう軸。双極（00）を結ぶ、最初に引かれる1本の線。
* **Y, Z**: Xだけでは「線」にしかならない。線が面・立体として安定するために、Xと直交する2つの軸 Y, Zが要る。

X, Y, Zの3軸が揃って初めて、「どこにあるか」を過不足なく指し示せる。これが位置の3次元である。

## 2. 手のひらに見る XYZ

X, Y, Zは抽象的な座標軸である前に、身体で確かめられる幾何学でもある。

片手を開いたとき、親指の伸びる方向がX軸、手のひらの左右の付け根が広がる方向がY軸・Z軸をなす。5本の指先は、この座標系の上に立つ三角双錐の頂点となる（[`00-dual-pole.md`](00-dual-pole.md) 3節「手のひらの幾何学」）。

つまりXYZは、双極（00）から生まれた「線」が、面へ、立体へと閉じていく過程そのものの座標である。

## 3. 回転軸 π と、閉じた単位「1」

$$XYZ\pi = 1$$

X, Y, Zの3軸だけでは、まだ「開いた」座標系にすぎない。そこに回転軸 π が加わることで、3軸は一つの閉じた球（単位「1」）として自己完結する。

* πは、X, Y, Zのどれか特定の1軸ではなく、3軸をひとつの構造として束ね、回転させて閉じる働きを担う。
* $XYZ\pi = 1$ は、「空間的な細胞（自律した1つの構造）が成立するための条件」を表す式である。これが満たされて初めて、位置の3次元は単なる座標の集合ではなく、自律した「1つの単位」になる。

πの数学的な性質（オイラーの公式との関係）は [`euler-connection.md`](euler-connection.md) で扱う。

## 4. エネルギー単位系との対応

位置側（本稿）とエネルギー側（[`OOO-pi.md`](OOO-pi.md)）は、同じ構造を持つ対の関係にある。

| | 位置（本稿） | エネルギー（OOO-pi.md） |
| :--- | :--- | :--- |
| 3軸 | X, Y, Z | O, O, O（3つのスピン） |
| 閉じる軸 | π（回転軸） | π（回転軸） |
| 単位条件 | $XYZ\pi = 1$ | $OOO\pi = 1$ |
| 問い | どこにあるか | どちらを向いているか |

この2つの単位系が揃って、初めて $P = xX + yY + zZ + uU + vV + wW$ という1つの状態空間モデルが成立する。
