# オイラー公式との接続 — Connection to Euler's Formula

*理論ドキュメント — [`00-dual-pole.md`](00-dual-pole.md) で導入した回転軸 π の数学的な裏付け。[`XYZ-pi.md`](XYZ-pi.md) と [`OOO-pi.md`](OOO-pi.md) の両方がここを参照する。*

## 0. 位置づけ

$XYZ\pi = 1$、$OOO\pi = 1$ という2つの単位条件は、いずれも回転軸 π が3つの軸を「閉じて」1つの自律した単位にする、という同じ働きに支えられている。この「閉じる」という操作の、数学的にもっとも小さな表現がオイラーの公式である。

## 1. 回転を指数として書く

$$e^{i\theta} = \cos\theta + i\sin\theta$$

オイラーの公式は、「回転を指数として書く」という発見である。角度 θ だけ回転するという操作が、$e^{i\theta}$ という1つの式に折りたたまれる。三四式で繰り返し現れる「回転軸 π」を数学的に扱う土台は、ここにある。

## 2. θ = π — 1が半回転して、自分の反対側に出会う

$$e^{i\pi} = -1$$

「1」が半回転（π）すると「−1」になる。これは、1が自分の反対側に出会うということである。

この、1つの点が半回転して自分の対極と重なるという構造が、三四式でいう「00（双極）の誕生」に対応する（[`00-dual-pole.md`](00-dual-pole.md) 1節「誕生は2から始まる」）。1という一つの存在が、πだけ回転すると、自分とは正反対の−1という点になる。「1と、その反対側」という最小の関係こそが、双極（00）の数学的な最小モデルである。

## 3. θ = 2π — 一周して、元の場所に戻る

$$e^{i \cdot 2\pi} = 1$$

一周すると、元の場所に戻る。これは、細胞が分裂しても「1という構造」自体は保存される、ということに対応する。分裂は構造の終わりではなく、「1の回転周期が完成した」ということにすぎない（[`cell-division.md`](cell-division.md)）。

$e^{i\pi} = -1$（双極の誕生）と $e^{i \cdot 2\pi} = 1$（周期の完成）は、同じ回転の、途中と終わりを示している。

## 4. 四元数への拡張 — OOOπ の数学的な姿

複素数 $e^{i\theta}$ が扱えるのは、1つの平面上の回転だけである。3次元空間での回転を最小の形で閉じて表現するには、3つの虚数軸（i, j, k）とスカラーからなる**単位四元数**への拡張が要る。

$$q = a + bi + cj + dk, \qquad a^2 + b^2 + c^2 + d^2 = 1$$

* スカラー部 **a**: 回転角に対応する成分 → 回転軸 **π**
* 虚数部 **(b, c, d)**: 3つの回転軸に対応する成分 → 3つのスピン **O, O, O**

三四式の $OOO\pi = 1$ は、まさにこの「3つの双極的スピンと回転軸からなる、単位の回転系」として機能している（[`OOO-pi.md`](OOO-pi.md)）。四元数のノルムが常に1に保たれること（$a^2+b^2+c^2+d^2=1$）は、$OOO\pi = 1$ という単位条件——エネルギー的な細胞が自律した1つの構造として成立する条件——と同じ形をしている。

## 5. まとめ

| 三四式の言葉 | 数式 | 意味 |
| :--- | :--- | :--- |
| 双極（00）の誕生 | $e^{i\pi} = -1$ | 1が半回転し、自分の反対側に出会う |
| 顕在化・周期の完成 | $e^{i \cdot 2\pi} = 1$ | 一周して、1という構造が保存されたまま戻る |
| 空間単位系 | $XYZ\pi = 1$ | 3つの位置の軸が π で閉じ、1つの単位になる |
| エネルギー単位系 | $OOO\pi = 1$ | 3つのスピンが π で閉じ、1つの単位になる |
| 両者の数学的な最小表現 | $q = a+bi+cj+dk,\ \lvert q\rvert=1$ | スカラー a が π、虚数部 (b,c,d) が O, O, O に対応する |
