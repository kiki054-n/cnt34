# 三四式：六位一体の精神円環モデル
> **— 認識・態度・志向・実践・純化・還元の深層ロジックによる人間精神の成長と社会形成 —**

「三四式」は、伝統的な哲学・道徳・神道・仏教的境界を超克し、個人の精神的解脱と社会的な創造発展を一つの不可分な循環として紐解く精神統合モデルです。

「一（真潔）」から始まり、「六（創生）」へと至る6つの概念は、互いに独立した言葉ではなく、深層において密接に結びつき、絶えず自己更新し続ける**「六角形（ヘキサゴン）の円環」**を構成しています。

---

## 1. 六つの根本概念（Six Core Concepts）

| 位 | 概念 | 階層 / 領域 | 深層ロジック |
| :---: | :--- | :--- | :--- |
| **一** | **真潔** (Shinketsu) | **倫理・純化** | 私心・エゴ・偽りを削ぎ落とし、動機を純粋に保つ起点 |
| **二** | **唯心** (Yuishin) | **世界観（認識）** | 万物の根源は「心」であり、自他不可分であると悟る |
| **三** | **惟神** (Kannagara) | **生き方（態度）** | 人為を捨て、天地・自然の無為自然な摂理に身を委ねる |
| **四** | **友惟** (Yuui) | **個人・実践** | 見返りを求めず、目の前の他者を「友」として深く慈しむ |
| **五** | **友朋共生** (Yuuho-Kyosei) | **社会・結実** | 個の真摯な思いやりが集い、共に栄える調和した社会を築く |
| **六** | **創生** (Sousei) | **実相・還元** | 調和した社会から新たな価値を生み出し、原点へ還流させる |
