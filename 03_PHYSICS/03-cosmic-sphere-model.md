# 全体均衡モデル — 境界づけられた球体と零点収束

*理論ドキュメント 03 — 物理と精神の6軸ベクトル場を、境界を持つ1つの球体として統合し、その内部での動的な均衡を記述する。[`02-dynamic-model.md`](02-dynamic-model.md) の動的記述を、系全体のスケールに拡張したもの。*

## 0. 位置づけ

[`01-basic-equation.md`](01-basic-equation.md) で $P=xX+yY+zZ+rR+iI+jJ$ という静的記述を、[`02-dynamic-model.md`](02-dynamic-model.md) でその時間発展を扱った。本稿では視点をさらに広げ、無数の $P$（あるいは $\mathbf{E}$）が1つの閉じた系の中でどう釣り合うかを扱う。

本稿の内容は現時点でいくつかの点が未証明の**仮説・公理**であり、そのことを本文中で明示する。数学的な厳密化はまだ途上にある。

## 1. 世界観の核心

宇宙の物理的実体と人間の精神構造をともに、**「境界を持つ球体（Boundary Enclosed Sphere）」**として捉え、その内部における力学と心理の動的な釣り合いを、1つの高次元ベクトル場として記述する。

この世のすべての運動・意識の変容・相互作用は、物理世界と精神世界という双極が描く高次元空間のベクトルとして表され、系全体のベクトルの総和は最終的に0（零点・動的平衡）へ収束する、という像を仮説として置く。

$$\sum \mathbf{V} = \mathbf{0}$$

## 2. 幾何学的構造 — 球体と境界

```
                    【境界（Boundary / 地平線）】
           /─────────────────────────────────────────────\
          /   [物理世界（p軌道：外的空間）]                \
         /      xX (空間・行動)  yY (時間・経験)           \
        |       zZ (場・関係)                              |
        |                                                  |
        |                     ● [原点 0]                   |
        |               (ベクトルの総和 ＝ 0)                |
        |                                                  |
         \      rR (欲求・意志)  iI (共感・関係性)         /
          \     jJ (倫理・全体貢献)                       /
           \  [精神世界（d/f軌道：内的深層）]             /
            \────────────────────────────────────────────/
```

* **境界（Boundary）**: 外部と内部を分かち、動的なエネルギーや意識を球体内部に留める領域。
* **内部空間（Interior）**: 物理的自由度（$p$ 軌道）と精神的自由度（$d/f$ 軌道）が交錯する、[`02-dynamic-model.md`](02-dynamic-model.md) の6次元構造。
* **中心・原点（Origin 0）**: すべての力・運動・情念が打ち消し合い、調和（零点）へと戻ると仮定する平衡点。

### 「$S^3$」という言葉について

上の図は2次元の断面図だが、本稿の元となる着想では、この境界を**超球体（$S^3$ 空間）**——有限でありながら端を持たない位相構造として思い描いている。これは閉じた宇宙論（フリードマン宇宙の閉じたモデルにおける、空間切片としての3次元球面）からの**比喩的な借用**である。

重要な留保として、本稿のどの計算も、実際に $S^3$ の曲率・測地線・計量を使ってはいない。現時点で $S^3$ は「有限だが境界のない全体」を思い描くためのイメージであり、装飾的な位置づけにとどまる。実際の計算にこの位相構造を組み込むかどうかは、今後の課題とする。

## 3. 6軸の対応

軸の意味（$X,Y,Z$＝物理、$R,I,J$＝精神）と、$p$軌道／$d,f$軌道とのアナロジーは [`02-dynamic-model.md`](02-dynamic-model.md) の1章で定義した通りである。本稿ではこれをそのまま用いる。

## 4. 運動方程式とゼロへの収束

### 4.1 全状態のテンソル表現

物理項（[`02-dynamic-model.md`](02-dynamic-model.md) で定義した $\mathbf{r}_{phys}\otimes\boldsymbol{\omega}$）と精神項 $\mathbf{m}_{psych}=r\mathbf{R}+i\mathbf{I}+j\mathbf{J}$ を合わせて、系全体の状態を次のように表す。

$$\mathbf{E}_{total} = \underbrace{\left( \mathbf{r}_{phys} \otimes \boldsymbol{\omega} \right)}_{\text{物理行動 ⊗ 回転}} \;\oplus\; \underbrace{\mathbf{m}_{psych}}_{\text{精神的深層ベクトル}}$$

ここで記号を「$+$」ではなく「$\oplus$（直和）」とした。$\mathbf{r}_{phys}\otimes\boldsymbol{\omega}$ は $3\times3$ の2階テンソル（9成分）、$\mathbf{m}_{psych}$ は1階のベクトル（3成分）であり、階数の異なる空間に属する。両者を単純に足し合わせることはできないため、$\mathbf{E}_{total}$ は $(\mathbb{R}^3\otimes\mathbb{R}^3)\oplus\mathbb{R}^3$、すなわち12次元の空間に属する量として定義する。

回転 $\boldsymbol{\omega}$ の合成に特異点のないクォータニオン演算を用いるかどうか、また時間 $t$ をこの構造のどこに位置づけるかは、本稿では扱わない。この2点は次稿で改めて検討する。

### 4.2 零点収束の公理（仮説）

球体内部のすべての物理力場・精神ベクトルの、境界における総和が0へ収束する、という主張を次の式で表す。

$$\oint_{\text{境界}} \mathbf{E}_{total} \cdot d\mathbf{A} = \mathbf{0} \qquad \text{かつ} \qquad \sum_{k} \mathbf{V}_k = \mathbf{0}$$

**この式は証明された定理ではなく、本モデルが置く公理（postulate）である。** 形式的にはガウスの発散定理と同じ形をしており、「境界内部に正味の湧き出し・吸い込みがなければ、境界を通る流束の総和はゼロになる」という**条件付きの恒等式**にすぎない。つまりこの式そのものは、それだけで自動的に成り立つものではなく、

> 物理空間で生じた作用は、精神空間における反作用によって必ず相殺される（＝系内部に正味の湧き出しがない）

という前提を置いて初めて成立する。本稿ではこの前提を証明せず、公理として採用する。なぜこの相殺が起きると言えるのか——その根拠づけは、今後の課題として残す。

#### 公理が主張する収束のメカニズム

1. **作用と反作用の対置**: 物理空間（$x,y,z$）で発生した過剰なベクトル（行動・歪み）は、精神空間（$r,i,j$）における反作用（倫理・共感・内省）を生み、相互に打ち消し合う——という仮定。
2. **動的循環**: 発散しようとするベクトルは境界に反射・回帰し、球体内部を巡りながら中心（原点0）へ向けて散逸・安定化する——という仮定。

## 5. 結論（仮説として）

本モデルは、物理（テンソル場・回転運動）と精神（意志・共感・倫理）を分断せず、「境界づけられた球体における高次元ベクトルの調和運動」として一元化しようとする試みである。ベクトルの総和が0に収束する、という像は、現時点では証明ではなく、理論の出発点となる公理として置いている。
